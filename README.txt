Linux Atlas — Interactive Linux learning website
================================================
- Open index.html in a modern browser.
- Place your downloaded local font files in ./fonts/.
- CSS tries WOFF2, then WOFF, then TTF for each declared weight.
- Expected example names are listed below. If your actual filenames differ, update the matching @font-face URLs in style.css.

IBM-Plex-Sans-Arabic-Regular.woff2 / .woff / .ttf
IBM-Plex-Sans-Arabic-Medium.woff2 / .woff / .ttf

The website uses no external Google Fonts requests. If you only have some weights, either add the corresponding font files or remove the relevant @font-face declaration. The virtual terminal is a safe in-browser simulator; it does not execute commands on the host operating system.
Content is based on the uploaded lecture PDF: Linux introduction, GNU, history, architecture, components, distributions, and applications. Additional explanations are educational elaborations.
